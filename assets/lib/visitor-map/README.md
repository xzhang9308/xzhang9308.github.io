# Visitor map assets

- `d3-array.min.js`: d3-array 3.2.4, ISC license (included).
- `d3-geo.min.js`: d3-geo 3.1.1, ISC license (included).
- `countries.json`: Natural Earth 1:110m admin-0 boundaries, public domain;
  properties reduced to region code, name, and label position.
  Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson

All assets are served locally. Geography is illustrative; points mark country/region
label positions, not individual visitors. No analytics data is bundled here.
